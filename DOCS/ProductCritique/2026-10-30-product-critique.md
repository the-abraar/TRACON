## Findings (most severe first, max 8)
- [High] B1 not fixed: the local secret is served to any local program — `packages/avalokita-engine/src/server.ts:225-226` (meta tag in every local HTML page), `:152` (`GET /api/flights` has no auth), `:213-214` (POST needs only that secret) — An `npm install` script or a prompt-injected agent with one allowed Bash call can `GET 127.0.0.1:4040/`, regex the secret, list held decisions, and `POST /api/answer {allow:true}` for every pending permission in every Claude profile. The supervised agent can approve itself. Frame headers were added (`:228`), which only stops websites, not local processes. — evidence: code unchanged from the critique's reproduction; the code's own `shortcut:` at `:31-32` and README:262 admit it; judge 2026-10-19 still lists it under "Fixed".
- [High] B2 still open: a hung-but-listening engine blocks the terminal for up to an hour — `packages/tracon-cli/src/hooks.js:9` (`type: "http"`, `timeout: 3600`) — If the engine is stopped (Ctrl-Z, debugger, swap) but its port still accepts connections, every `AskUserQuestion`/`ExitPlanMode` and permission hook in every profile waits up to 3,600 s. CODING_STANDARDS calls this "the worst bug this app can have". The 500-on-throw handler (`server.ts:187-195`) does not help a stalled process. — evidence: still a bare HTTP hook, no command-hook wrapper with a short deadline.
- [Medium] Stuck holds up to `HOLD_MAX_MS` (~58 min) — `packages/avalokita-engine/src/decisions.ts:15`, `:104-113` — A permission is released only after the sweep has once seen its call pending in the transcript and then sees it resolved. If the terminal answers before the first sweep, `seen` stays false and the card (ALLOW/DENY live) sits on the phone for 58 minutes; a long allowed command shows as held until its result is written. Answering that stale card returns "ok" but does nothing. — evidence: no `PostToolUse` release hook exists; TODO.md "Not verified yet" asks the owner to check this exact case.
- [Medium] One malformed Antigravity line can stop the engine — `packages/avalokita-engine/src/parsers/agy.ts:37`, `airspace.ts:200-203`, `server.ts:117` — `tool_calls` that is not an array throws; there is no per-line try/catch, and the first `snap()` at `server.ts:117` runs outside any catch, so `startEngine` rejects and launchd (`KeepAlive`, 10 s throttle) crash-loops it until the file ages out of the 30-min window. The runtime poll now catches (`server.ts:253-261`), but it then drops the rest of that batch on every tick. — evidence: probe above throws.
- [Medium] MultiEdit permissions are approved blind on main — `packages/tracon-ui/src/components/decisions/answer.ts:29-39`, `:48-50` — `permissionBody` handles only `Write`, `permissionDiff` only `Edit`; a MultiEdit card shows only `file_path`. (`NotebookEdit` is also blind.) — evidence: fix exists only on `feat/multiedit-card` (`f3ad7bb`, PR #2, unmerged).
- [Low] `tracon service install` drops env config — `packages/tracon-cli/src/service.js:18-43`, `bin/tracon.js:13-14` — The plist has no `EnvironmentVariables`, so `TRACON_PORT`, `TRACON_REMOTE_PORT`, `TRACON_STATE`, `TRACON_WINDOW_MIN` set in the shell are lost. Hooks installed with `TRACON_PORT=5050` point at 5050 while the service listens on 4040: TRACON silently never holds anything (fails open, so not dangerous, just broken). If 4040 is taken, KeepAlive restarts the engine every 10 s forever. — evidence: judge 2026-10-27 "Still open" confirms.
- [Low] Tailnet identity still in public git history — commits `3b12d51` (added) and `0f1981d` (removed from tree) — `abraars-macbook-pro.tail09801e.ts.net`, `100.124.124.14`, `100.81.75.72` are readable by anyone in the public repo's history. Not reachable from the internet; it identifies the owner's devices and the exact origin of the partner app. Removed from the current tree (only the placeholder `mac.tail0.ts.net` remains in tests). — evidence: `git log -p --all | grep ts.net`.
- [Low] Held-while-present permissions all push at once when you go away — `server.ts:120-122`, `decisions.ts:93-97` — holds created while at the desk are never marked pushed, so flipping to away pushes every one, including hour-old ones. — evidence: unchanged from critique B7.

## Claims vs reality
- "Fixed 2026-10-19: any program on the Mac could approve permission prompts" (judge.md:122) -> false. Only blind POSTs are stopped; a program that first GETs `/` gets the secret (`server.ts:225-226`). README:262 is more honest ("does not stop a program running as your own user") but still says "a stray script can't approve a prompt with a blind POST", which invites the wrong reading.
- "If TRACON isn't running, every prompt behaves exactly as it does today" (TODO.md Notes, README) -> true only when nothing listens on the port; false for a stalled engine (B2).
- "Gap 4 closed for Write, Edit and MCP; a MultiEdit card still shows only its path" (judge 2026-10-27) -> true on main; MultiEdit fix only on `feat/multiedit-card`.
- "Gap 6 done in code: tracon service install" (judge 2026-10-27) -> true, minus env vars (`TRACON_PORT` not carried, admitted).
- "Download the latest beta (beta_0.1)" / `brew install the-abraar/tap/tracon` (README:27-38) -> true but stale: that build has no partner app, hooks, `pair` or `away` (admitted at README:186). decision.md:41's four launch fixes: LICENSE done; secret half-done; release with partner app not done; slides still show the 2026-10-16 screenshots (critique: a client's folder name), never re-shot.
